# Memories

This folder contains distilled learnings from strategic planning sessions, research, and key decisions made during FlashNote's development. These documents serve as reference material for future product decisions.

## Purpose

- Preserve context and rationale behind major decisions
- Provide quick reference for recurring questions
- Maintain institutional knowledge as the product evolves
- Inform future strategic discussions without re-researching

## Naming Convention

Files are named with the date and topic:
```
YYYY-MM-DD-topic-description.md
```

## Contents

| File | Summary |
|------|---------|
| `2026-02-04-business-strategy-financial-analysis.md` | Financial projections, churn analysis, retention strategies, moat assessment, personalization architecture, clinic accounts design, acquisition positioning |

## Usage

When making product decisions, check if a relevant memory exists. These documents capture:
- Market research and competitive analysis
- Financial modeling and unit economics
- Technical architecture decisions
- Prioritization rationale
- Open questions identified for future exploration
