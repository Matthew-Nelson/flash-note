<objective>
Add 44px minimum touch targets to all interactive elements, cursor-pointer to all clickable elements, and refine the prefers-reduced-motion media query to exempt functional spinners while keeping decorative animations instant.

Purpose: These are global foundation changes that affect every page. Button.tsx and the CSS component classes are shared across the entire app, so fixing them here propagates everywhere. The reduced-motion refinement is a WCAG compliance fix that prevents functional loading indicators from being invisible to users who prefer reduced motion.

Output: Updated Button component, CSS component classes, design tokens, and individual component touch target fixes across Alert, Sidebar, Footer, and MarketingNav.
</objective>
