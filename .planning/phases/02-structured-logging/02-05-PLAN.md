**1. Fix pino-pretty dev transport in logger.ts (line 78):**

Add `sync: true` to the pino-pretty transport options in the dev branch. This forces pino-pretty to write synchronously to stdout instead of using a worker thread, which bypasses the known Turbopack issue where worker thread stdout is not relayed to the dev terminal (vercel/next.js #84766, #86099).

Change the transport options object at line 78 from:
```typescript
options: {
  colorize: true,
  ignore: 'pid,hostname',
  translateTime: 'HH:MM:ss.l',
},
```
to:
```typescript
options: {
  colorize: true,
  ignore: 'pid,hostname',
  translateTime: 'HH:MM:ss.l',
  sync: true,
},
```

Add a code comment above `sync: true` explaining why:
```typescript
// Sync mode bypasses pino-pretty's worker thread, which Turbopack
// does not relay to the dev terminal (vercel/next.js #84766).
// Only used in dev -- production uses GCP JSON (no pino-pretty).
```

NOTE: `sync: true` has a minor performance cost (blocks the event loop during log writes) but this only affects dev mode. Production uses GCP JSON format with no pino-pretty transport at all.
