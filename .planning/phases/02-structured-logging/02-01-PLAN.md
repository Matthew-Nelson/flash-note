    2. Create `web/src/lib/telemetry.ts` (client-safe -- no 'server-only'):
       - `TELEMETRY_URL = '/api/telemetry'`
       - `sendTelemetry(payload: Record<string, unknown>)`: fire-and-forget. Try `navigator.sendBeacon(TELEMETRY_URL, new Blob([JSON.stringify(payload)], { type: 'application/json' }))`. If sendBeacon unavailable, fall back to `fetch` with `keepalive: true`. Entire function wrapped in try/catch that swallows all errors -- telemetry must never throw.
       - `initClientTelemetry()`: Guard with `typeof window === 'undefined'` check. Register:
         - `window.addEventListener('error', ...)` -> sendTelemetry with type 'unhandled_error'
         - `window.addEventListener('unhandledrejection', ...)` -> sendTelemetry with type 'unhandled_rejection'
       - `reportErrorBoundary(error: Error, digest?: string)`: sendTelemetry with type 'error_boundary', message, stack, digest, url

    3. Create `web/src/app/api/telemetry/route.ts`:
       - Import logger from `@/server/lib/logger`
       - Import `createRequestLogger` from `@/server/lib/request-logger`
       - Import `telemetryRateLimit`, `checkRateLimit` from `@/server/lib/rate-limit`
       - Define `telemetrySchema` with Zod:
         ```typescript
         const telemetrySchema = z.object({
           type: z.enum(['unhandled_error', 'unhandled_rejection', 'error_boundary']),
           message: z.string().max(1000),
           stack: z.string().max(5000).optional(),
           digest: z.string().max(100).optional(),
           url: z.string().max(500).optional(),
           componentStack: z.string().max(2000).optional(),
         });
         ```
       - `export async function POST(request: NextRequest)`:
         - Extract IP: use x-forwarded-for rightmost-minus-trusted-proxy pattern consistent with request-context.ts. Since this is a Route Handler (has direct request access), read from `request.headers.get('x-forwarded-for')`. Use the TRUSTED_PROXY_COUNT from config.
         - Rate limit check: `checkRateLimit(telemetryRateLimit, ip)`. If not success, return `NextResponse.json({ ok: true })` silently.
         - Parse body: Try `await request.json()`. If that fails (sendBeacon text/plain edge case), try `await request.text()` then `JSON.parse()`.
         - Validate with telemetrySchema.parse(body). On ZodError, return `{ ok: true }` silently.
         - Create request logger with trace correlation: `const reqLogger = createRequestLogger(request)`
         - Log: `reqLogger.error({ source: 'client', errorType: event.type, stack_trace: event.stack, url: event.url, digest: event.digest }, '[Client] ' + event.message)`
         - Return `NextResponse.json({ ok: true })`
         - Wrap entire handler in try/catch returning `{ ok: true }` on any unexpected error

       - `web/src/app/api/telemetry/route.test.ts`: Mock `@/server/lib/logger` and `@/server/lib/rate-limit`. Test valid/invalid payloads, rate limiting, body parsing fallback.
